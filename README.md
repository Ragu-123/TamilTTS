# TamilTTS

A highly optimized 68.5M parameter Text-To-Speech engine explicitly designed for the Tamil language.

## Architecture Highlights
- **Text Encoder**: ALBERT-based transformer for deep contextual phonetic understanding.
- **Style Encoder**: Zero-shot reference voice cloning.
- **Diffusion Prosody**: Human-like pacing, pitch, and pauses.
- **Vocoder**: HiFi-GAN for crystal-clear output.
- **Critics**: WavLM (Emotion) & AI4Bharat IndicWhisper (Phonetics / SR-FD).
